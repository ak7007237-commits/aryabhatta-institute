# Aryabhatta Institute — Production Website

Premium responsive Next.js website for Aryabhatta Institute.

## Stack
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Included
- Responsive premium landing page
- Director & Main Faculty profile
- Course overview for 6th–10th, 11th–12th, B.Sc. and M.Sc.
- Teaching methodology and Mathematics topics
- FAQ
- Admissions / WhatsApp CTA
- Call and WhatsApp quick actions
- SEO metadata
- Reduced-motion accessibility support
- Existing Amit Kumar profile image retained
